# 液态玻璃外观

首页现在使用带柔和色彩的背景、半透明材质和边缘高光。顶栏、Dock、搜索框、下拉面板、设置和对话框采用分层玻璃效果；视频卡片使用轻量透明底色，保持标题和封面清晰。

## 启用

新安装默认开启玻璃效果。已有配置会保留；如果升级后没有看到透明效果，请在 **设置 → 常规 → 毛玻璃和性能** 中关闭 **禁用毛玻璃效果**。

- 浅色和深色模式均有对应的高光、边框和阴影。
- 未设置壁纸时，背景使用跟随主题色的柔和渐变。自定义壁纸和遮罩仍按原设置显示。
- **降低毛玻璃模糊强度** 会降低导航和弹层的模糊半径。
- **禁用毛玻璃效果** 使用实色表面；**禁用阴影** 移除投影。
- 系统的减少动态效果、减少透明度偏好会得到尊重。不支持背景模糊的浏览器使用实色背景。

## 实现

材质变量集中在 `src/styles/liquidGlass.scss`，在原有变量之后加载，同时支持页面根节点和扩展的 Shadow DOM。

- `--bew-glass-sheen`：表面高光。
- `--bew-glass-border`：透光边缘。
- `--bew-glass-ambient`：无壁纸时的背景渐变。
- `--bew-glass-card` / `--bew-glass-hover`：卡片底色和悬停状态。
- `--bew-filter-glass-1` / `--bew-filter-glass-2`：普通表面和对话框的背景模糊。

顶栏的模糊放在不接收鼠标事件的伪元素上，避免改变菜单的定位。视频卡片不使用逐卡片背景模糊，长列表只绘制底色、边框和阴影。高光为静态渐变，无新增动画循环、图片资源或运行时依赖。

## 验证

构建：`pnpm build`。静态检查：`pnpm typecheck --noEmit`。现有测试：`pnpm exec vitest run`。

浏览器检查项目：

1. 首页浅色 / 深色，视频卡片、搜索输入、搜索建议和设置面板。
2. 1440px、768px、390px 窗口下的布局。
3. 禁用玻璃、降低模糊强度、禁用阴影及其切换。
4. 系统减少动态效果与减少透明度偏好。
5. 原有壁纸和主题色配置。

## 本地安装构建产物

将 `extension/` 文件夹打包或复制到固定位置。在 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions` 打开开发者模式，选择“加载已解压的扩展程序”，选中包含 `manifest.json` 的文件夹，然后刷新 Bilibili 页面。
